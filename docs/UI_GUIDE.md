# Home Server Monitor UI Guide

## Dashboard rules

- Avoid horizontal scrolling at 1920x1080.
- Use short, consistent panel and column names.
- Show zero instead of No data when zero is the correct state.
- Use Unavailable only when collection really failed or is unsupported.
- Keep Home focused on current state and navigation.
- Keep Storage and RAID ownership separate.
- Use the same status vocabulary everywhere: Healthy, Warning, Critical, Unavailable.
- Use green, yellow, orange, and red for health states; reserve blue for information.
- Each panel should answer one operational question.
